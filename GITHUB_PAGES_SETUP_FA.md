# انتشار MyLife v1.4 روی GitHub Pages

1. همه فایل‌های داخل پوشه `MyLife_v1.4` را در ریشه Repository قرار بده؛ `index.html` باید مستقیم در Root باشد.
2. در GitHub: Settings → Pages → Build and deployment.
3. Source = Deploy from a branch.
4. Branch = main و Folder = /(root)، سپس Save.
5. آدرس سایت به شکل `https://USERNAME.github.io/MyLife/` خواهد بود.
6. برای Google Drive، فایل `GOOGLE_SETUP_FA.md` را انجام بده و Client ID را فقط در `config.js` بگذار.
7. کاربران نهایی فقط دکمه «اتصال حساب Google» را می‌بینند و Client ID یا رمز را داخل MyLife وارد نمی‌کنند.

## نصب
- Android: سایت HTTPS را در Chrome باز کن → Install app / Add to Home Screen.
- iPhone/iPad: در Safari → Share → Add to Home Screen.
- Desktop: در Chrome/Edge گزینه Install را بزن.
